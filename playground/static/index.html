mcp-audit playground

Paste an MCP server manifest, get a security audit. The same 28 checks the CLI runs, in your browser: injected instructions in tool descriptions, over-broad tools, exposed secrets, dangerous tool pairs, and the rest, each with a plain-English fix.

Your manifest is audited in memory by the playground backend and forgotten. Nothing is stored. The share link below carries the manifest in the URL itself, not on a server.

Tip: the vulnerable example comes back with 11 findings, 2 of them critical. The clean example comes back with none. That gap is the whole demo.

No audit yet. Paste a manifest and hit Audit manifest, or start with the vulnerable example.

Built on mcp-audit, a deterministic manifest scanner with no model calls. A finding is a pointer, not a verdict: read the remediation, check the actual server, then decide. Running the backend yourself takes two commands, see playground/README.md in the repo.
